# Patient Management API 🏥

A professional backend system built with **FastAPI** and **Pydantic** to manage patient records with automated health metrics and JSON data persistence.

## 🚀 Key Features
- **Full CRUD Functionality:** Create, Read, Update, and Delete patient records.
- **Automated BMI Calculation:** Input height and weight to receive a real-time BMI score and health verdict.
- **Data Sorting:** Sort the patient database based on height, weight, or BMI results.
- **Interactive Documentation:** Built-in Swagger UI for testing all API endpoints.

## 🛠️ Technology Stack
- **Framework:** FastAPI
- **Data Validation:** Pydantic
- **Server:** Uvicorn
- **Storage:** JSON (Local Database)
